## The Aesthetic Shift

Was going for that clean, glass vibe initially but I couldn't do it well so, I Scrapped all the
rounded corners and smooth blurs. <br>
We are going full brutalist red cyberpunk one now. so hence, Absolute zero black backgrounds, max
reds & monospace everywhere.  <br>

I want this to feel like a raw data feed straight from a server rack at 3AM (xD), not a dashboard.
and the raw feeling also perhaps makes it slightly unsettling/scary to look at
Still gotta hook up the actual Wakatime OAuth and pull real stats down instead of these dummy
hardcoded ones, but the UI shell is getting there. The grid overlay and scanlines were a pain in ahh
but they sell the look.
